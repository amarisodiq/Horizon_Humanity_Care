# Horizon Humanity Care — Website

A responsive Next.js landing website for Horizon Humanity Care.

## Stack
- Next.js 15
- React 19
- TypeScript
- CSS
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Important
- The selected Horizon Humanity Care logo is stored at `public/images/logo.png`.
- Replace/keep the exact supplied logo artwork; do not recolour or redraw it.
- The contact form is currently a front-end demo and does not send email. Connect it to Formspree, FormSubmit, Resend, or your backend before production.
- Verify the final organization name, registration status, contact details, social links and domain before launch.
